## Decisions (2026-08-26)

- Component library: **shadcn/ui** (Radix base) over Radix Themes, Base UI raw, Park/Ark, Mantine/Chakra/HeroUI, Tremor, daisyUI — Tailwind-native, copy-in, overlaps with the existing Headless UI + Heroicons stack.
- Tailwind upgraded v3 → v4 first (official codemod).
- Table engine: **TanStack Table v9** (`useTable` + `tableFeatures`); filtering/sorting stays in `utils/grant-filters.ts` (CSV parity), table runs `manualSorting`.
- Visual direction: the mockup — IBM Plex Sans body, tracked-caps condensed headers/nav, grey paper, navy for links and amounts, hairline rules both directions.
- Default columns: Date · Purpose · Funder · Amount · Source · ✎. Recipient and Cause hidden behind a `+` in the header row (persisted in localStorage). Click a row to expand full purpose + recipient/via/sponsor/round/cause/source.
- Source column = short source label linked to the record, plus `· via X` only when X isn't the funder or the source itself.
- Scope of this branch: home table + shared header/nav. Other pages restyled in follow-ups.
